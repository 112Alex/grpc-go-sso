# grpc-go-sso

Микросервис авторизации на gRPC с поддержкой SSO.  
Проект находится в разработке.

## Структура монорепозитория

- **sso/** — основной сервис авторизации (Go)
  - `cmd/sso/` — точка входа (main.go)
  - `internal/` — бизнес-логика, gRPC-сервер, конфиги, логирование
  - `config/` — конфигурационные файлы (например, local.yaml)
  - `lib/` — вспомогательные библиотеки (логирование и др.)
  - `go.mod`, `go.sum` — зависимости

- **protos/** — protobuf-контракты и сгенерированные Go-файлы
  - `proto/sso/` — исходные .proto-файлы
  - `gen/go/sso/` — сгенерированные gRPC и protobuf Go-файлы
  - `go.mod` — отдельные зависимости для работы с protobuf
  - `Taskfile.yaml` — задачи для генерации и сборки

## Как работает

- Основной сервис (`sso/`) реализует gRPC API для авторизации.
- Контракты и структуры сообщений описаны в папке `protos/`.
- Сгенерированные файлы из `protos/gen/go/sso/` подключаются как зависимости через GitHub.
- В проекте предусмотрена интеграция с внешним хранилищем и сервисом авторизации (пока TODO).
